# Start here

Use this route to review Q-Orbit without reading every historical document first.

1. **Research:** Read the [V1.0-RC3 manuscript](../deliverables/Q-Orbit_Scientific_Manuscript_V1.0-RC3.md). Its title block and boundary statement define what the study claims.
2. **Recorded facts:** Consult the [Canonical Facts Record](../deliverables/Q-Orbit_Canonical_Facts_Record.md), dated 28 August 2026. It is a source record with a stated evidence hierarchy and historical open items.
3. **Numerical package:** Open the [frozen model package](../models/q-orbit-theoretical-device-imperfection-propagation-v0.16-ta1/). Keep this folder intact to preserve relative input paths and the original checksum manifest.
4. **Interactive view:** Start the [analysis console](../prototype/README.md). Its data is a separate preserved snapshot; do not assume that every standalone Drive export is byte-identical to every packaged file.
5. **Engineering:** Browse the [handbook and figures](../engineering/), including the V0.3 architecture package and V0.2 illustration notes. All illustrations are conceptual.
6. **Review trail:** Read the [D8 response](../deliverables/Q-Orbit_D8_Response_to_Reviewers.md), [claim ledger](../deliverables/Q-Orbit_Manuscript_Claim_Ledger.md), and [review files](../reviews/).

The repository preserves original records rather than updating historical status statements by inference. New verification performed for this import is described separately in [Reproducibility](REPRODUCIBILITY.md).
