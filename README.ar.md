# Q-Orbit

**دراسة نظرية للتوزيع الكمي للمفاتيح عبر الأقمار الصناعية**

[English](README.md) · [دليل القراءة](docs/START_HERE.md) · [الورقة البحثية](deliverables/Q-Orbit_Scientific_Manuscript_V1.0-RC3.md) · [النموذج التفاعلي](prototype/README.md)

## فكرة المشروع

يدرس Q-Orbit كيف تتغير نتائج نموذج للمفاتيح الكمية محدودة الطول عند تغيّر افتراضات المصدر والكاشف، وما الأدلة المطلوبة قبل ربط النتائج النظرية بأجهزة حقيقية. يجمع المشروع بين نموذج عددي، وبيانات محاكاة، ووثائق تصميم هندسي، وسجلات مراجعة تحدد حدود الاستنتاجات.

المشروع **بحث نظري وعددي**. الرسوم الهندسية تصوّر المفهوم، والنتائج لا تعني اختبار أجهزة فعلية أو إطلاق قمر صناعي أو اعتماد أمني أو إنتاج مفاتيح سرية تشغيلية.

## النتائج المسجّلة

تحتوي الحزمة على شبكة حسابية من ١٦٨١ نقطة، منها ٥٦٨ ذات هامش نظري موجب و١١١٣ غير موجبة. هذه أعداد نقاط ضمن شبكة محددة، وليست احتمال نجاح مهمة. تسجّل الحزمة أيضًا ١٢ اختبارًا و٢٠ فحص تدقيق ناجحًا؛ وهي نتائج السجل الأصلي، وليست ادعاء بإعادة تشغيل الدراسة كاملة عند تجهيز هذا المستودع.

## تشغيل الواجهة محليًا

بعد تنزيل المستودع، شغّلي الأمر التالي من مجلده:

</div>

```bash
python3 -m http.server 8461 --bind 127.0.0.1 --directory prototype
```

<div dir="rtl">

ثم افتحي **http://127.0.0.1:8461**. تحتوي الواجهة على تسعة أقسام لاستكشاف النتائج والافتراضات والمراجعات.

## حفظ الأصول

حُفظت أسماء الملفات الأصلية ومحتوياتها، مع إبقاء الإصدارات المختلفة واضحة وحزمة النموذج مترابطة. تحتفظ الوثائق المؤرخة بتوصيفاتها الأصلية، بما فيها الحالات المقيدة مثل `PRIVATE-BLOCKED`؛ إتاحة المستودع لا تغيّر صلاحية النتائج العلمية أو حالة الاعتماد التشغيلي.

راجعي [دليل إعادة التحقق](docs/REPRODUCIBILITY.md) و[خريطة الملفات](docs/REPOSITORY_MAP.md) للتفاصيل.
